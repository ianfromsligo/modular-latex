\begin{proof}[Proof of Corollary~\ref{cor:2d-nonexistence}]
Suppose a separable walk on a $k \times m$ torus admits a full-state
revival at step $N$, so $U_{k \times m}^N = e^{i\Phi} I_{4km}$.
By the factorisation $U_{k \times m} = U_k \otimes U_m$
(Eq.~\eqref{eq:factorised_unitary}), this is equivalent to
$U_k^N = e^{i\phi_x} I_{2k}$ and $U_m^N = e^{i\phi_y} I_{2m}$
simultaneously. By Theorem~\ref{thm:1d-nonexistence}, no such $N$ exists
when $k \notin \{2,3,4,5,6,8,10\}$ and $k \le \Kmax$, and the same holds
for $m$. If $k$ and $m$ are both admissible but
$\mathcal{N}_k \cap \mathcal{N}_m = \emptyset$, no common step count
exists, so no full-state revival exists.
\end{proof}
