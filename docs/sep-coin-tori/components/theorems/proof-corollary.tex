\begin{proof}[Proof of Corollary~\ref{cor:2d-existence}]
The 2D evolution operator factorises as
$U_{k \times m} = U_k \otimes U_m$ following the tensor-product
decomposition established in Eq.~\eqref{eq:factorised_unitary}. If
$k, m \in \{2,3,4,5,6,8,10\}$, Theorem~\ref{thm:1d-existence} supplies
1D witnesses $U_k^{N_x} = e^{i\phi_x} I_{2k}$ and
$U_m^{N_y} = e^{i\phi_y} I_{2m}$. If
$\mathcal{N}_k \cap \mathcal{N}_m \neq \emptyset$, choose a common step
count $N \in \mathcal{N}_k \cap \mathcal{N}_m$. Then
$U_{k \times m}^{N} = U_k^N \otimes U_m^N = e^{i(\phi_x + \phi_y)}
I_{4km}$, which is the stated revival.
\end{proof}
