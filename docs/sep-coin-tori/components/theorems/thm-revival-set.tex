\begin{theorem}[1D existence]
\label{thm:1d-existence}
A discrete-time quantum walk on a 1D cycle graph $\mathbb{Z}_k$ driven by
Dukes' coin $C(\rho,\delta) \in \mathrm{U}(2)$ admits a non-trivial
full-state revival with coin parameter $\rho \in (0,1)$ for every
$k \in \{2, 3, 4, 5, 6, 8, 10\}$.
\end{theorem}
