Periodicity is a fundamental aspect of physics and a clock is an
essential component of most computer systems. An analogous phenomenon
occurs in the quantum realm: under certain conditions on symmetric
topologies, a quantum walker returns to its initial state, both
position and spin, after some number of steps. We call this a
\emph{full-state revival}. Such revivals have been proposed as a
resource for quantum memory \cite{Chandrashekar2015} and for quantum
state routing \cite{Steinfurth2025}, as a system that returns
periodically to a previous state can serve as a clock, a register, or
a routing primitive.

Here we consider a discrete-time quantum walk (DTQW) with a separable
four-dimensional coin. For a DTQW, $U$ is the single-step operator of
the walk. A full-state revival at period $N$ means $U^N = I$: the
operator is the identity, so every state returns to itself with no
phase after $N$ steps. A related phenomenon also occurs along the
walk: the state may return to itself up to an unobservable global
phase, $U^N = e^{i\phi} I$ for some $\phi \neq 0$. We call this a
\emph{projective} revival. The classification in this paper is of
full-state revivals in the strict sense, $U^N = I$; the projective
revivals are noted where they occur but are not the object of
classification.
