\subsubsection{Period $N = 6$}
The period $N=6$ is realised by $139$ parameter sets across $2\\times2$, $2\\times4$, $4\\times4$. The reflection parameters take values in $\{$0.2500$, $0.2679$, $0.2764$, $0.2929$, $0.3333$, $0.5000$, $0.7236$, $0.7500$, $0.8038$, $0.8292$, $0.8787$\}$, and the phase parameters in $\{$0.0000\pi$, $0.5000\pi$, $0.6667\pi$, $0.7500\pi$, $0.8000\pi$, $0.8333\pi$, $1.0000\pi$, $1.2000\pi$, $1.2500\pi$, $1.6000\pi$\}$. This period is realised on a small set of highly symmetric
tori.
