\par
Every square torus $L_x = L_y$ for $L_x \in \{2, 3, 4, 5, 6, 8, 10\}$
admits a revival. Non-square tori revive only when their two
revival-period sets intersect. The reduced classification lists
only one orientation of each non-square pair; the $L_y \times L_x$
case follows by exchanging the two axes.
