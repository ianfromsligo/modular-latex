\par
The phase parameters are the dominant feature of the 2D
classification. In the 1D case, $\delta$ affects only the
eigenvectors of $U_k$; the eigenvalues, and hence the
revival period, depend solely on $\rho$. This simplicity
does not survive the tensor product. In 2D, the eigenvalues
of $U_{k \times m}$ are products $\lambda_i \mu_j$, and a
period-$N$ revival requires $\lambda_i^N = \mu_j^N = 1$
simultaneously. The phase parameters $\delta_x, \delta_y$
control which pairs of 1D eigenbases can be aligned. As
Table~\ref{tab:delta-summary} shows, only $23.0\%$ of the
classification has $\delta_x = \delta_y = 0$; the remaining
$77\%$ involves non-zero phases, and $64.4\%$ requires
unequal phases on the two axes. This is the essential new
feature of the 2D case: the phase parameters are a
selection mechanism, not merely a gauge.
