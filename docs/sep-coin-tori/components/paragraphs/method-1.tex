The classification proceeds in two stages.

\emph{Stage one} is the 1D search. We swept $\rho$ on a grid of
resolution $10^{-4}$ and $\delta$ over twenty rational multiples of
$\pi$, evaluating the root-of-unity residual at every grid point for
each $N \le \Nmax$ and each $k \le \Kmax$. Candidates below a
threshold of $10^{-3}$ were refined by bounded minimisation followed
by a local sweep, and accepted only after independent verification by
matrix exponentiation. The search reproduced every entry of Dukes'
classification \cite{Dukes2014} and found no revival for any
$k \in \{7, 9, 11, 12, 16\}$. The script and raw output are available
in the accompanying repository.

\emph{Stage two} is the 2D pairing. The tensor-product factorisation
$U_{k \times m} = U_k \otimes U_m$ of
Eq.~(\ref{eq:factorised_unitary}) reduces the 2D problem to matching
the revival period sets of the two axes. For each pair $(k, m)$ with
$k, m \in \{2, 3, 4, 5, 6, 8, 10\}$, we take the common periods
$N \in \mathcal{N}_k \cap \mathcal{N}_m$ and record every combination
of 1D parameters that produces the revival, verifying each candidate
by matrix exponentiation. Because both stages are exhaustive over the
search bounds, the resulting classification of $209$ inequivalent
parameter sets is complete within those bounds. The full set of
values is available at \cite{full_revivals_references}.
