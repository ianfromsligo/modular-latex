The duality $\rho \leftrightarrow 1-\rho$ holds without
exception: wherever $(\rho_x, \rho_y, \delta_x, \delta_y)$
admits a revival at some period $N$, so does the set obtained by
replacing any occurrence of $\rho$ with $1-\rho$ and leaving all
other parameters fixed. This follows directly from the symmetry of
the dispersion relation under $\rho \to 1-\rho$, and it halves the
number of independent reflection values to be tabulated.
