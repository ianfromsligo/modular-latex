The classification has a clear shape. In 1D, exactly seven
cycle lengths admit revivals, and they do so for a small
finite set of coin parameters. In 2D, this finite set spreads
out through the tensor factorisation: $24$ tori revive, at
$30$ distinct periods, with $4{,}773$ canonical parameter
sets in total. The distribution is highly uneven. The
$2 \times 2$ torus alone contributes $1{,}196$ sets; the
tori $2 \times 3$, $2 \times 4$, and $2 \times 6$ each
contribute several hundred more. This concentration reflects
the fact that $k = 2$ revives at every even period, so any
torus involving a $2$-cycle inherits a large family.
