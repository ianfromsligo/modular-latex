\par
We now interpret the classification of Section~\ref{sec:results}.
The reduced dataset comprises $4773$ parameter sets
across $24$ torus sizes and $30$
distinct revival periods spanning every even integer from $N = 2$
to $N = 60$. Three structural features organise the classification.
First, the period spectrum is sharply peaked: the three most
populated periods account for $N=54$ ($659$), $N=58$ ($361$), $N=30$ ($332$) parameter sets, while
the majority of periods carry only a handful of sets each.
Second, the reflection parameters take a small fixed set of
algebraic values, with the duality $\rho \leftrightarrow 1-\rho$
holding throughout.
Third, the phase parameters are uniformly rational multiples of
$\pi$, with denominators tied to the torus dimensions.
