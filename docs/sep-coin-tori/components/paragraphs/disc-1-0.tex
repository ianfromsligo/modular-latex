\par
We now interpret the classification of Section~\ref{sec:results}.
The reduced dataset comprises $4773$ parameter sets
across $24$ tori and $30$
revival periods. Three features organise the data. First, the
period spectrum is sharply peaked: the most populated periods are
$N=54$ ($659$), $N=58$ ($361$), $N=30$ ($332$), while most periods carry only a handful of sets.
Second, the reflection parameters take a small fixed set of
algebraic values, with the duality $\rho \leftrightarrow 1-\rho$
holding throughout. Third, the phase parameters are uniformly
rational multiples of $\pi$, with denominators tied to the torus
dimensions.
