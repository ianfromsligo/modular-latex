\subsubsection{Period $N = 56$}
The period $N=56$ is realised by $96$ parameter sets across $2\times2$, $2\times3$, $2\times4$, $2\times6$, $3\times3$, $3\times4$, $3\times6$, $4\times4$, $4\times6$, $6\times6$. The reflection parameters take values in $\{0.1454, 0.1916, 0.2831, 0.3774, 0.3923, 0.5202, 0.5233, 0.7793, 0.8974\}$, and the phase parameters in $\{0.0000\pi, 0.2500\pi, 0.7500\pi, 1.0000\pi, 1.2500\pi, 1.7500\pi, 2.0000\pi\}$. This is one of the longest periods in the classification,
and is confined to a small number of tori whose revival
period sets intersect at a large common value.
