Extending the classification framework established by Dukes
\cite{Dukes2014} for 1D cycle graphs, we provide the first complete
theoretical classification of 2D separable discrete-time quantum walks
on $k \times m$ toroidal lattices. We observe that separable coins
maximise the class of intrinsic full-state revivals on this topology
compared to their non-separable counterparts [add ref]. A key feature of the 
above work was to generalise the coin based on two parameters.  $\rho$, the 
reflection parameter which dictates the split ratio of the wave packet between
the two adjactent nodes of the walk.  $\delta$ is the phase parameter and it 
determine s the relative arrival times of the wave packet to each of the 
adjacent nodes.  Continuing to the torus in 2D, we need to have a general coin 
with reflection and phase parameters in the x and y planes.  Hence we define $\rho_x, \rho_y, \delta_x, \delta_y$ as our parameters.
