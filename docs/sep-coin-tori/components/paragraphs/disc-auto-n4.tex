\subsubsection{Period $N = 4$}
The period $N=4$ is realised by $16$ parameter sets across $2\\times2$. The reflection parameters take values in $\{$0.5000$, $0.5359$, $0.5858$, $0.6667$\}$, and the phase parameters in $\{$0.8333\pi$, $1.0000\pi$, $1.2500\pi$, $1.3333\pi$\}$. This period is realised on a small set of highly symmetric
tori.
