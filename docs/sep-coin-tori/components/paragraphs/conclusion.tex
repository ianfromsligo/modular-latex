\section{\label{sec:conclusion}Conclusion}
We have presented a full classification of full-state revivals for
separable discrete-time quantum walks on $k \times m$ toroidal
lattices. A torus exhibits a full-state revival whenever both
dimensions belong to the $1$D revival set and their revival-period
sets intersect; no revival exists outside this class within the
search bound $k, m \le 16$, $N \le 60$. The classification is
complete for $k, m \le 10$ and, for $k = 7$ and $k = 9$, $1$D
non-existence is proved at any step count. The reduced
classification contains $4773$ parameter sets across $24$ tori. The
longest revival period $N = 60$ occurs on the small $5 \times 5$
torus, inverting the classical intuition that larger systems
support longer revivals. These results open new directions for
quantum state routing and quantum memory architectures.
