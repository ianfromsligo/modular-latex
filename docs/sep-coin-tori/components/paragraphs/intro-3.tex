In a key aspect of the 1D framework, the coin operator was parameterised by a
real amplitude $\rho$ and a relative phase shift $\delta$. In practice,
$\rho$ dictates the spatial splitting ratio of the wave packet as it
transitions to the two adjacent nodes, while $\delta$ determines the relative
phase that the wave packet accumulates between these divergent paths. To 
extend this idea to toroidal lattices using a separable coin, we need parameters
in the x and y axes, $C_x \otimes C_y$, 
This means our toroidal walk is governed by a
four-parameter space: $\{\rho_x, \delta_x, \rho_y, \delta_y\}$. By
matching this expanded parameter space against the
root-of-unity spectral constraints established in 1D for revivfals, we 
can determine the totality of intrinsic full-state revivals available on 2D
tori.
