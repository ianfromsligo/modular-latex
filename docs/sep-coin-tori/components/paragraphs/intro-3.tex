A key aspect of the 1D work saw the coin operator parameterised by a
real amplitude $\rho$ and a relative phase shift $\delta$. In practice,
$\rho$ dictates the spatial splitting ratio of the wave packet as it
transitions to the two adjacent nodes on a walk. The $\delta$ parameter determines the relative phase that the wave packet accumulates between these 
divergent paths as the walk progresses. 
To extend this idea to 2D toroidal lattices using a separable coin, 
we need parameters in the x and y axes, $C_x \otimes C_y$, 
This means our toroidal walk is governed by a
four-parameter space: $\{\rho_x, \delta_x, \rho_y, \delta_y\}$. By
matching this parameter space against the
root-of-unity spectral values established for 1D for revivfals, we 
can determine the total set of intrinsic full-state revivals on 2D tori.
