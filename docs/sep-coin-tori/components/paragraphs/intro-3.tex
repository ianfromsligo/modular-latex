\par
Dukes \cite{Dukes2014} classified full-state revivals on 1D cycle graphs.
Using this work as a baseline, we extend that classification to separable
discrete-time quantum walks over 2D toroidal lattices. Using a separable coin
means a 2D coin factorises into independent 1D coins on each axis on 
$k \times m$ torus, thus maximising the revival count.
Our classification considers the only admissible cycle lengths 
$k, m \in \{2, 3, 4, 5, 6, 8, 10\}$ with revival periods up to $N = 420$. 
In the classification process we perform an exhaustive search of the 
parameterised coin 1D space, a reduction step that removes redundant entries 
and then we proceed via tensor factorisation to find all revivals on 2D tori.
