\subsection{The $10 \times 10$ revival: a case study}
The $10 \times 10$ torus is the largest torus in the classification
that admits the longest period $N = 60$, and it provides a clean
illustration of the revival mechanism. We take the reflection
parameters $\rho_x = \rho_y = (5-\sqrt{5})/10 \approx 0.2764$ and
set $\delta_x = \delta_y = 0$.
