In Dukes' framework, the coin is parameterised by a real
amplitude $\rho$ and a relative phase $\delta$. Extending this
to a 2D toroidal lattice, the tensor product of independent
coins on each axis, gives a four-parameter space
$\{\rho_x, \delta_x, \rho_y, \delta_y\}$. We report the
classification as a set of records of the form
$(k, m, N, \rho_x, \delta_x, \rho_y, \delta_y)$, each giving a
torus, a revival period, and the coin parameters.

The 1D search reproduces every revival tabulated by Dukes and
finds exactly one additional revival, at $k = 2$, $N = 60$,
$\rho \approx 0.0146$, $\delta = 2\pi/3$.
