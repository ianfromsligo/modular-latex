Limitations of this experiment include:

\begin{itemize}
    \item No revivals found on $3 \times 3$ or $3 \times 4$ tori with
          any Bell coin
    \item The $4 \times 4$ torus revives only with $\Phi^+$ and
          $\Psi^+$ (period 24)
    \item The $\Psi^-$ coin shows no revivals on $4 \times 4$
\end{itemize}
